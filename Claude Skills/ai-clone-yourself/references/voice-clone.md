# Voice cloning and delivery

A face clone with a flat voice fails faster than a slightly imperfect face with a convincing voice. Listeners forgive visual oddity; they do not forgive delivery that sounds like a label being read.

## Why default AI delivery sounds wrong

Standard synthesis treats every word the same. There is no emphasis on the words that matter, no pause where a person would breathe, and no melody - no rise and fall across a sentence. The ear catches all three immediately, even when it cannot name what is wrong.

Everything below is about restoring those three things: emphasis, pause, melody.

## Recording voice samples

- **Quiet room, soft surfaces.** No fan, no traffic, no air conditioning, no echo.
- **Consistent microphone distance.** Moving closer and further between lines teaches the clone an inconsistent tone.
- **Your real register.** Read in the voice you actually want in content, not a radio voice. If you clone a performance, you have to perform forever to match it.
- **Variety of expression:** a serious passage, a lighter one, a question, an emphatic point, and a passage with deliberate pauses.
- **Natural pace.** Speaking faster than normal for the recording produces a clone that always sounds rushed.
- **Enough material**, following the platform's minimum, and more if the voice has to carry long-form.
- **No processing.** No noise reduction, compression, EQ or de-essing on the source. Clean capture beats processed capture.

## The delivery description

Lock one sentence describing the delivery and reuse it unchanged, every time. This is the same mechanism as a video voice blueprint: even a one-word change can shift the output's tone or pitch noticeably, so treat it as a fixed string, not a description to rewrite.

Pattern: **accent, pace, tone, texture.**

> light Australian accent, relaxed and confident, medium pace, bit of vocal rasp

Why an accent matters even when it is subtle: it changes the whole delivery system - vowel shapes, rhythm, where stress lands. Those micro-details are what the ear reads as a real person. It also narrows the engine's voice pool, which is exactly what makes the voice repeatable across weeks of content.

## Delivery styles to adapt

Each of these is a reusable description; insert the accent you want and keep the rest fixed.

| Style | Description |
|---|---|
| Conversational | subtle [accent], natural mid-tempo pacing, friendly and relaxed tone, brief pauses before key words as if thinking, sentences tapering off slightly rather than ending sharply |
| Confident | light [accent], steady deliberate delivery, calm authority, controlled pacing with clear pauses between statements, never rushed |
| Energetic | subtle [accent], fast lively rhythm, enthusiasm rising on the point, animated and expressive, like someone excitedly sharing a story |
| Casual | light [accent], loose conversational pace, sounds like talking to a close friend, occasionally breaks sentences, natural fillers, relaxed and informal |
| Storytelling | light [accent], expressive cadence, pacing varying naturally - slower in description, faster in the exciting part - carrying curiosity and subtle emotional shifts |
| Calm and thoughtful | subtle [accent], slower reflective pace, soft tone with gentle pauses between ideas, like someone choosing words carefully |
| Persuasive | light [accent], confident rhythm, slight emphasis on important words, small pauses before key statements, composed |
| Professional | subtle [accent], clean controlled delivery, medium pace, clear pronunciation with slight pauses between sentences, polished |
| Dramatic | light [accent], deliberate cinematic pacing, longer pauses for tension, emphasis on emotional words, weight and seriousness |
| Curious and analytical | subtle [accent], thoughtful pace with slight hesitation before ideas, inquisitive, as if exploring the topic while speaking |
| Friendly and warm | light [accent], gentle rhythm, soft welcoming tone, flowing speech with small natural pauses |
| Playful | subtle [accent], relaxed tempo with slight vocal smirk, emphasis shifting unpredictably to highlight humour |
| Authority | light [accent], controlled confident cadence, slow enough to command attention, strong emphasis on decisive words |
| Reflective | subtle [accent], slower pacing with introspective pauses, voice softening on emotional phrases, almost thinking out loud |
| Conversational story mode | light [accent], casual narrative rhythm, like explaining an experience to a friend, sentences occasionally restarting mid-thought |
| Fast social style | light [accent], quick clipped rhythm, high energy, minimal pauses, lands the point before the viewer can scroll |

Choose the accent that matches the person. A mismatch between face and voice is more noticeable than either flaw alone.

## Punctuation is the pacing tool

Write scripts with the pauses in them. More punctuation gives the engine rhythm; none gives you a monotone read.

- **Ellipses** for a real beat: "I didn't believe it either... until I tried it."
- **Commas** for short breaths, used more liberally than written English wants.
- **Full stops over conjunctions.** "It's cheaper. It's faster. That's it." reads better than one long sentence.
- **Dashes** for an interruption in thought.
- **Italics or capitals on one word** per paragraph where the engine supports emphasis - sparingly; everything emphasised is nothing emphasised.
- **Keep sentences short.** Long sentences are where synthesis flattens.

Then close the script with the delivery description so the engine gets both the content and the voice in one pass.

## Checking a take

- Does any sentence sound like a sentence being read rather than said?
- Is there a breath where a person would breathe?
- Does the pitch move across the sentence, or is it flat?
- Are numbers, acronyms and names pronounced correctly? (Spell them phonetically if not.)
- Does it still sound like the same person as last week's video?

## Multilingual and localisation

Voice cloning in other languages makes localisation a service you can sell - the same founder video, several markets, same voice. Two cautions: have a native speaker check the script and the output before it ships, because mispronunciation and awkward phrasing are invisible to a non-speaker; and adjust pacing per language rather than reusing timing, since the same content runs at different lengths.

## Keeping the voice stable over time

- Store the delivery description with the clone's documentation and copy-paste it, never retype it.
- Keep the original samples archived for re-cloning on a better engine later.
- If the voice drifts, check for a reworded description before blaming the engine - that is the cause nine times out of ten.
- Re-record samples when the use case changes materially (short form to long form, for instance), not because output was poor once.
