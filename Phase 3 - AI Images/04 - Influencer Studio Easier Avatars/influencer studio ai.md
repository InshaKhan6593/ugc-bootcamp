# How to Use Influencer Studio for AI

Lesson Support Guide

## What you're building

Use Influencer Studio to build repeatable AI personas instead of making random one-off images. The goal is to create an influencer profile that can show up consistently across outfits, locations, post styles, camera angles, captions, and social formats while still feeling like the same person.

![](influencer%20studio%20ai_images/img_p2_2.jpg)

screenshot: Influencer Studio interface showing a profile for "vikky @vikky" with generated images of a woman in different settings

Influencer Studio keeps one AI persona organized inside a dedicated workspace, with generated content staying tied to that profile.

<!-- page 3 -->

## 1. Start with a premade influencer when learning the workflow

The fastest way to understand Influencer Studio is to start with a premade influencer. Pick the person who already feels closest to the content you want to create. Their base identity affects what kind of posts will feel natural later.

* Use premade influencers to learn the workflow quickly.

* Choose based on the content style you want, not just the best-looking face.

* A fitness-style persona, luxury lifestyle persona, or beauty persona will naturally suit different posts.

* Rename the influencer once selected so the profile feels like your own asset.

screenshot: Choose Premade Influencer modal showing various avatar options including Alessia, Isla, Hannah, Valentina, Camille, Mila, and Natasha

![](influencer%20studio%20ai_images/img_p3_2.jpg)

The premade influencer modal lets you choose a ready-made avatar before building content around that persona.

## 2. Understand the influencer workspace

Each influencer gets their own workspace. This is the main advantage: feed content, presets, captions, and generation controls stay organized under that specific persona instead of scattered across random generations.

* Feed is where generated posts land.

* Presets help create batches without writing every prompt from scratch.

* Captions generates post copy and hashtags.

* The prompt bar creates new images or videos while keeping the influencer identity in context.

![](influencer%20studio%20ai_images/img_p4_2.jpg)

screenshot: AI Video Bootcamp influencer workspace interface showing feed, presets, and caption tabs with a prompt bar

The workspace separates Feed, Presets, and Captions so one influencer can be managed like a real creator profile.

## 3. Generate feed content with the prompt bar

The feed tab is where you describe what the influencer is doing, wearing, and where the photo should take place. Because the profile already knows the influencer, you do not need to keep uploading the same identity references every time.

* Use simple prompts when testing fast ideas.

* Use longer prompts when you need stronger control.

* Include action, location, outfit, camera style, lighting, expression, and vibe.

* Drag useful outputs back into the prompt bar when you want to guide the next generation.

screenshot: AI Video Bootcamp interface showing a prompt for an influencer named Becky

![](influencer%20studio%20ai_images/img_p5_2.jpg)

The feed prompt bar already has context for the influencer, so prompts can focus on the scene, outfit, lighting, and action.

## 4. Choose aspect ratio based on the platform

Do not leave the aspect ratio random. Choose it based on where the post will be used. TikTok, Reels, and Shorts usually need 9:16. Instagram feed posts may use 4:5 or square. The format should match the final platform.

* Use 9:16 for TikTok, Reels, Shorts, and vertical story-style content.

* Use 4:5 or 1:1 for Instagram-style image posts.

* Keep the ratio consistent across a content batch when possible.

* Use the reference option when pose, product, outfit, or location needs extra control.

screenshot: AI video generation interface showing aspect ratio selection menu

![](influencer%20studio%20ai_images/img_p6_2.jpg)

Aspect ratio and reference controls should be chosen before generating so the output matches the platform and creative goal.

## 5. Use Presets for fast content batches

Presets are one of the fastest ways to create content because you can choose prebuilt categories instead of starting from a blank prompt. Categories like daily aesthetic, luxury, fitness, night out, and product placement give you a structured batch of post ideas.

* Use daily aesthetic for casual lifestyle posts.

* Use night out for restaurants, events, parties, and evening outfit content.

* Select multiple categories to generate a content pack.

* Use preset prompts as starting points when you do not know what to create next.

screenshot: AI Video Bootcamp interface showing preset categories like Daily Aesthetic, Product Placement, Mirror Selfie, Life Content, Luxury, Fitness, Scroll Stopper, and Night Out

![](influencer%20studio%20ai_images/img_p7_2.jpg)

Preset categories help generate a structured content batch without needing to manually write every idea from scratch.

## 6. Generate captions and hashtags for the post

Once the image is created, use the Captions tab to generate post copy and hashtags. Add context so the caption has a clear angle instead of sounding generic.

* Choose caption length based on the post style.

* Use shorter captions for luxury or aesthetic content.

* Use motivational captions for fitness or transformation-style posts.

* Add context like what happened, where the influencer was, or what the post should say emotionally.

* Edit the generated caption before posting so it still feels human.

screenshot: AI Video Bootcamp interface showing the Caption Generator tool for an influencer profile named Becky

![](influencer%20studio%20ai_images/img_p8_2.jpg)

The Captions tab turns a generated image into usable social content by adding caption copy and hashtags.

## 7. Create a custom influencer when you need a specific persona

If none of the premade influencers fit, create your own. The custom form lets you define the influencer's name, gender, age range, style, aesthetic, hair colour, eye colour, and extra details. You can also upload reference images for stronger control.

* Name the persona based on the vibe you want.

* Use age, gender, aesthetic, hair, and eye colour to define the base look.

* Add details like tattoos, haircut, features, and overall style in the prompt box.

* Upload references only if they are clear, well-lit, and visually consistent.

## 8. Use references carefully when building custom avatars

References can improve control, but bad references make the avatar worse. Avoid blurry, heavily filtered, inconsistent, or conflicting images. If you upload references, make sure they all support the same visual direction.

* Use clear images with good lighting.

* Keep reference style consistent.

* Avoid faces that are blurry or over-filtered.

* Do not mix references that look like different people.

* Generate options, then choose the strongest avatar before building content around it.

## 9. Choose from the generated avatar options

After you submit the custom influencer form, the platform gives multiple avatar options. Pick the one that best matches the brand, content style, and long-term use case, not just the first one that looks good.

* Check whether the face feels usable across many posts.

* Choose an avatar that fits the niche or brand category.

* Look for a face and style that can handle multiple outfits, locations, and products.

* Avoid choosing an option that only works for one very narrow scene.

## 10. Use the prompt formula for stronger content

Short prompts can work, but the best results still come from structured prompting. A simple formula inside Influencer Studio is: action, location, outfit, camera style, look, lighting, mood.

* Action: what the influencer is doing.

* Location: where the post takes place.

* Outfit: what they are wearing.

* Camera style: iPhone, flash, candid, studio, mirror selfie, etc.

* Lighting and mood: natural daylight, warm indoor light, luxury, casual, fitness, UGC.

## The big idea

Influencer Studio is useful because it turns one AI persona into a content system. Instead of generating random images, you can build a reusable creator profile, generate feed posts, batch ideas through presets, write captions, and create consistent brand or client content around the same identity.

* Use premade influencers to learn the workflow fast.

* Use custom influencers when the persona needs to match a specific brand direction.

* Use presets when you need a content batch quickly.

* Use captions to finish the post instead of stopping at the image.

* Use structured prompts when the output needs to feel specific and realistic.
