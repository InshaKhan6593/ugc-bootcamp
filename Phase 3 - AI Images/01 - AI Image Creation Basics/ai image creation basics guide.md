## AI Image Creation Basics in Studio

Lesson Support Guide

<!-- page 2 -->

## What you're building

Use this guide to understand the absolute basics of creating AI images inside Studio. Almost every AI workflow starts with an image: characters, product shots, social ads, thumbnails, avatars, cinematic scenes, and visuals that can later be animated into video.

Good image generation is not just typing a random sentence and hoping for the best. Strong results usually come from four things working together: a clear prompt, the right model, the right settings, and strong reference images when needed.

<!-- page 3 -->

## 1. Start with the prompt bar

The prompt bar is where you tell the AI what you want to create. Studio has different modes for image, video, and audio. The mode you choose changes the options available on the prompt bar.

For images, your prompt can be simple or detailed. A simple prompt might be: realistic fitness influencer taking a mirror selfie. A stronger prompt describes the person, environment, lighting, camera style, clothing, mood, and type of image you want.

Core idea

```text
Prompt = what you want the AI to create.
Settings = the format and quality of the result.
References = visual context for what the AI should follow.
```

<!-- page 4 -->

## 2. Choose the right image model

The model selector chooses which AI image model creates your image. Think of the model as the engine. Different models are better at different jobs, so changing the model can completely change the output even if the prompt stays similar.

* Some models are stronger for realism.

* Some are better for editing existing images.

* Some are faster and cheaper for testing ideas.

* Some are stronger for high-quality final outputs.

* Some work better when you are using references.

At the start, you do not need to know every technical detail. Just understand that if one model does not give the result you want, switching models can be a valid fix.

<!-- page 5 -->

## 3. Pick the right aspect ratio

Aspect ratio controls the shape of your image. The same prompt can look very different depending on the canvas shape, so choose the format before you generate.

* 16:9 is wide and works for YouTube, thumbnails, website headers, landscapes, and cinematic scenes.

* 9:16 is vertical and works for TikTok, Instagram Reels, YouTube Shorts, and most social video.

* 1:1 is square and works for profile images, product posts, carousels, and static ads.

Beginner mistake

`Do not generate half of a project in one aspect ratio and then switch halfway through. Stick to one aspect ratio per project unless you intentionally need multiple formats.`

<!-- page 6 -->

## 4. Use quality settings properly

Quality or resolution controls how detailed the output is. A 4K or higher-quality setting is useful when you need a stronger final image, but lower or faster settings can be useful when you are still testing an idea.

* Use faster/lower-cost settings while exploring ideas.

* Use higher-quality settings once the direction is working.

* Remember that advanced models, high resolution, and multiple outputs can cost more credits.

<!-- page 7 -->

## 5. Generate multiple outputs

AI image generation is not perfect on the first try. The output count setting lets you generate multiple variations from the same prompt. This is useful because one generation should not decide whether the idea is good or bad.

* Generate a few options from the same prompt.

* Pick the strongest result instead of judging the whole idea from one image.

* Use the best output as the next version to improve from.

<!-- page 8 -->

## 6. Use reference images correctly

A reference image is an image you upload to guide the AI. Instead of only describing something with words, you show the AI what you mean visually. References are one of the most important parts of AI creation.

* Use references for character consistency.

* Use references for product consistency.

* Use references for clothing, poses, locations, colours, framing, style, or overall vibe.

* Drag images from your desktop or reuse images already created inside Studio.

Your prompt should explain exactly how to use the reference. Do not upload an image and assume the AI knows what matters.

Reference prompt example

`Use the uploaded image as a character reference. Keep the same face, hairstyle, skin tone, body type, and overall identity, but place her in a luxury hotel lobby and change her outfit to an elegant black dress.`

<!-- page 9 -->

## 7. Be specific about what to preserve

Beginners often upload a reference but do not explain what the reference is for. The AI might copy the pose when you only wanted the face, or copy the background when you only wanted the outfit.

* If you want identity, say to preserve the face, hair, skin tone, and body type.

* If you want the outfit, say to preserve the clothing but change the location.

* If you want the product, say to preserve packaging, logo, shape, colour, and material.

* If you want pose only, say to use the image as a pose reference, not an identity reference.

<!-- page 10 -->

## 8. Use Assist and Wise Enhance carefully

Assist can help turn a rough idea into a more detailed and usable prompt. Wise Enhance can improve the prompt or make it more detailed before generation. These tools are useful when you are new, because you do not need to be an expert prompt writer straight away.

The warning is that enhanced prompts can sometimes add extra details you did not ask for. Always check the improved prompt and make sure it still matches your original idea before generating.

<!-- page 11 -->

## 9. Understand the @ button and saved assets

The @ button lets you quickly add saved characters or products. This is useful for consistency because you can mention your saved asset instead of repeatedly downloading and uploading the same references.

This becomes more important when building recurring characters, AI influencers, product campaigns, or a sequence of images that need to stay consistent.

<!-- page 12 -->

## 10. Generate, review, adjust, repeat

You are not supposed to get the perfect image every time. AI image creation is a creative process: generate, review, adjust, and generate again.

* If the face is good but the outfit is wrong, change the outfit part of the prompt.

* If the image looks too fake, add more realistic camera and lighting language.

* If the composition is wrong, adjust the camera/framing instruction.

* If the product changes too much, strengthen the reference instructions.

The big idea: image creation comes down to prompt, model, settings, and references. The prompt tells the AI what to create. The model controls how it creates it. The settings control format and quality. References guide the AI visually.
